# 9주차 과제 워크북 3 강의자 안내

- 대상: 교양 「인공지능과 데이터 활용」 9주차, 기존 도형 워크북 1·2 이후 확장 과제
- 권장 분량: 추가 45~60분 또는 개별 과제
- 핵심: Fashion-MNIST 10개 의류, HOG+SVM(사람이 설계한 특징)과 MLP(원본 픽셀) 비교, 데이터 누수 방지
- 공식 전체 데이터는 학습 60,000장/시험 10,000장. **실습은 고정된 학습 3,000장/평가 600장**을 사용하므로 전체 공식 데이터의 벤치마크 성능과 비교하지 말 것.
- 실행 확인: `fashion_mnist.load_data()`는 최초 실행 시 데이터 다운로드가 필요함. Colab TensorFlow, scikit-image, scikit-learn 설치 상태 확인.
- 유의사항: MLP는 CNN이 아니며 Teachable Machine과 동일한 구조가 아님. 두 모델의 정확도 우열을 사전 단정하지 말 것.
- 실습 완료 조건: 모델 2개 학습, 동일한 600장 평가, 그래프 및 CSV 파일, 서술형 질문 7개
- 수행평가 예시: 실행 25, 시각화·결과 25, 비교해석 30, 질문 20
- 데이터 출처: https://github.com/zalandoresearch/fashion-mnist (MIT)
