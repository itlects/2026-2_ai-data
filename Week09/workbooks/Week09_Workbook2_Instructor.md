# 9주차 추가 워크북 2 강의자 안내

- 목표: **이미지 왜곡이 모델 성능에 미치는 영향을 수치와 그래프로 비교**
- 권장시간: 35~40분 (데이터 확인 5, 시각화 8, 기본 분류 8, 증강 10, 보고 9)
- 자료: 9주차 기존 이미지 60장 사용. 별도 데이터 다운로드 불필요.
- 분할: 학습 45장, 원본 평가 15장. 변형별 평가도 같은 15장만 적용.
- 알고리즘: HOG + 선형 SVM / 데이터 증강은 훈련 이미지만 4조건으로 확장(총 180특징 벡터).
- 원본과 밝기 변형 간 정확도 차이가 작을 수 있음: 밝기 변화에 대한 HOG의 성질 논의.
- 모든 변형에서 증강 개선이 보장되는 것이 아님. 결과 수치를 학생이 직접 확인하게 할 것.
- 평가: 변형 이미지 관찰(20), 그래프(20), 학습 누수 방지(20), 증강 비교(20), 질문 답변(20).
