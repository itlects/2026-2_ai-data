# Week04 헬스케어 데이터관리

## 학습목표
- 걸음수·수면 형태의 웨어러블 데이터를 불러오고 품질을 점검한다.
- 결측치·범위 오류·비현실적 값을 식별한다.
- 규칙 기반 알림을 구현한다.
- Isolation Forest 기반 이상탐지를 적용한다.
- 규칙 기반과 AI 결과 차이를 비교한다.
