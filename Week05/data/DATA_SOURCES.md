## Google Drive에 저장된 데이터로 수업하기
- Drive `강의5주/02_데이터`에 같은 파일이 있다. 노트북 0장에서 `DATA_SOURCE = "drive"`로 바꾸면 Drive 데이터를 쓴다(학생은 공유 폴더를 '내 드라이브에 바로가기 추가' 후 사용).
- `krx_daily_3stocks_raw_ko.csv`가 폴더에 없으면 노트북이 종목별 CSV 3개로 **같은 파일을 다시 만들고** MD5로 원본과 동일한지 확인한다.
- Drive 연결이 어려우면 `DATA_SOURCE = "upload"`로 CSV와 `week05_MANIFEST.csv`를 직접 업로드한다.

## 원 출처
- 종목 시세: 한국거래소 정보데이터시스템 [전종목 시세](http://data.krx.co.kr) → 이를 매일 정리해 공개하는 [FinanceData/marcap](https://github.com/FinanceData/marcap) 저장소의 `marcap-2025.parquet`, `marcap-2026.parquet`에서 3종목만 추출
- KOSPI·KOSDAQ 지수: FinanceDataReader `fdr.DataReader('KS11')`, `fdr.DataReader('KQ11')` (FinanceData/fdr_krx_data_cache GitHub 캐시)
- 추출 스크립트: `Week05/tools/build_week05_data.py` (누구나 같은 결과를 재생성 가능)
- 추출일: 2026-10-15 (KST)

## 데이터 점검 결과 (추출 시점)
- 종목별 431거래일, 날짜 중복 0건, OHLCV 결측 0건, 거래량 0인 날 0건
- 기간 중 액면분할 없음 (상장주식수 변화는 자사주 소각 등으로 1% 내외) → 종가를 그대로 수익률 계산에 사용 가능
- 일간 등락률 최대 절댓값: SK하이닉스 29.95%, 삼성전자 26.81%, 현대차 16.22% (가격제한폭 ±30% 이내)
- 가격은 **수정주가가 아닌 당일 실제 체결가**다. 배당락 효과는 조정되어 있지 않다.

## 사용 조건
- 교육·연구 목적 비상업적 사용에 한한다. 원 데이터의 권리는 한국거래소에 있으며, 결과물에는 "출처: 한국거래소(KRX)"를 표기한다.
- 이 데이터와 분석 결과는 투자 권유나 매매 추천이 아니다.

## 학생이 직접 수집하는 방법 (심화)
`Week05/colab/Week05_데이터수집_API가이드.ipynb` 참고.

| 방법 | 키 필요 | 특징 |
|---|---|---|
| A. 이 폴더 CSV (GitHub raw URL) | 없음 | 수업 기본. 항상 같은 값이 나와 결과 대조 가능 |
| B. FinanceDataReader | 없음 | 종목 시세는 네이버 차트 서버를 거치므로 접속 제한 시 실패할 수 있음 |
| C. 공공데이터포털 금융위원회_주식시세정보 | 서비스키(무료, 회원가입 후 활용신청) | 공식 공공데이터, 영업일 기준 1일 1회 갱신(전 영업일 데이터) |
| D. KRX Open API | AUTH_KEY(회원가입 후 서비스별 이용신청) | 거래소 공식, 1회 호출 = 하루치 전종목 |
| E. 네이버 금융 화면 | 없음 | 눈으로 몇 개 값만 대조(교차검증)할 때 사용. 자동 수집(스크래핑)은 하지 않는다 |
