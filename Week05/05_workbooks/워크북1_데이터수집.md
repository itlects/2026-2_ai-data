# 워크북1 시세수집·전처리
1. 네이버금융 https://finance.naver.com/item/sise_day.naver?code=005930 의 일별 시세를 확인한다.
2. Colab에서 `!pip -q install finance-datareader` 실행.
3. `import FinanceDataReader as fdr`, `df=fdr.DataReader("NAVER:005930","2025-01-01","2025-12-31")` 실행.
4. 원본 CSV, 날짜 및 숫자 변환 후 중복/결측 제거 CSV를 각각 저장한다.
5. 다운로드 실패시 Drive 02_데이터의 DEMO CSV를 사용하며 실제 주가와 혼동하지 않는다.
