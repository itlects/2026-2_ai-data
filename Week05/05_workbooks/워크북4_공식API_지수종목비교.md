# 워크북4: 금융위원회 지수시세 + 개별 주식 시세 비교
- 금융위원회 주식시세 API: https://www.data.go.kr/data/15094808/openapi.do
- 금융위원회 지수시세 API: https://www.data.go.kr/data/15094807/openapi.do
- KRX API: https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd

학습 순서: 1) 활용신청·인증키 발급 2) 종목·지수 원본 CSV 수집 3) 날짜 및 수치형 변환 4) 일별 수익률 계산 5) 공통 거래일 기준 조인 6) 평균 수익률·변동성 비교 7) AI 보조 요약 근거 확인.
실제 API 키가 없을 때는 강의자가 사전 제공한 공식 CSV로 진행. 모의 CSV를 실데이터라고 표시하지 말 것.
