# Week13 교수자 가이드

## 수업 전 (10분)
1. 강의자 Colab을 열고 `파일 → Drive에 사본 저장`을 누른 뒤 0단계를 실행합니다. `✔ Colab AI 연결됨`이 나오는지 확인합니다.
2. 4~7단계를 한 번 실행해 실제 Gemini 응답을 확인합니다. v1에서 '사실표에 없는 숫자'가 실제로 몇 개 나오는지 적어 둡니다. 0개일 수도 있습니다. 모델이 '모른다'고 답하는 경우인데, 이것도 좋은 토론거리입니다.
3. 학생 링크는 노션 '전환 Cue'에 있는 학생 워크북 하나만 공지합니다.

## 기준 결과 (오프라인 예비 응답 기준)
| 버전 | 사실표에 없는 숫자 | 카드 4장 형식 | 본문 60자 초과 |
|---|---:|:-:|---:|
| 사람(예시) | 0 | ✔ | 0 |
| v1 | 8 | ✔ | 0 |
| v2 | 0 | ✘ | - |
| v3 | 0 | ✔ | 1 |
| v4 | 1 (39) | ✔ | 0 |

실제 Colab AI 응답은 실행할 때마다 달라집니다. 학생 결과가 표와 다르면 그 차이 자체를 토론 재료로 씁니다.

## 자주 생기는 문제
| 증상 | 원인 | 대응 |
|---|---|---|
| `⚠️ 오프라인 예비 응답 모드` | Colab 밖에서 열었거나 AI 사용량 한도에 걸림 | 실습은 그대로 진행합니다. 원하면 4-1의 `PASTE`에 Gemini 웹 결과를 붙여 넣습니다. |
| `카드 인식: 0 장` | AI가 형식을 지키지 않음(v2는 정상) | 다시 실행하거나 9단계에서 사람이 형식을 맞춥니다. |
| 한글이 네모로 보임 | 폰트 설치 실패 | `런타임 → 세션 다시 시작` 후 0단계부터 다시 실행합니다. |
| `NameError` | 위 셀을 건너뜀 | `런타임 → 이전 셀 모두 실행`을 누릅니다. |
| 블라인드 비교 안내만 나옴 | 3단계 사람 버전이 비어 있음 | 3단계를 작성한 뒤 다시 실행합니다. |
