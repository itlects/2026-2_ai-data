# Week 13 — 생성형 AI 콘텐츠 제작

가상 행사 자료를 바탕으로 사람 직접 작성, 기본 프롬프트, 개선 프롬프트의 결과를 비교합니다.

- event_briefs.csv: 교육용 합성 데이터 4행, 10열. 실제 행사가 아님.
- week13_student.ipynb: 학생용. Colab에서 Drive 사본 저장 후 실행.
- week13_instructor.ipynb: 강의자 시연용. 예시 결과는 실제 인간 작성 결과가 아닌 가상 기준문 및 AI 예시문.
- 저장 파일 week13_result.json은 학생 개인 작업 결과입니다.

API 키 없이 ChatGPT 웹에서 프롬프트를 실행하고 결과를 복사합니다. CPU에서 비교 코드를 실행하며 자동 점검은 정확 일치 여부만 확인합니다. 사람이 원자료와 문맥, 허위 추가, 저작권을 검토해야 합니다.
