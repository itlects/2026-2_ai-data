| 용도 | 파일 | 비고 |

| 강의자 화면 시연 | `notebooks/Week11_Instructor_Demo.ipynb` | 실행 결과와 예시 답변이 저장되어 있습니다. 열기만 해도 결과를 보여 줄 수 있습니다. |

Colab의 GitHub 링크나 Drive 링크로 열면 사용자마다 각자의 사본과 런타임이 생깁니다. 그래서 강의자가 시연 노트북을 실행해도 학생 노트북에는 영향이 없습니다. 학생에게는 첫 단계로 `파일 → Drive에 사본 저장`을 안내하세요.

scikit-learn 버전에 따라 랜덤 포레스트 값의 소수 셋째 자리가 조금 다를 수 있습니다. 그래도 MAE 순위는 같습니다.

## 강의 핵심 메시지
1. 가공은 분석의 절반입니다. 시간자료를 일자료로 바꾸는 집계, 빠진 시간 찾기, 결측 처리를 다룹니다.
2. AI는 약한 기준(7일 직선추세)보다는 0.77°C 낫습니다. 하지만 '어제 그대로'와는 0.01°C 차이에 그칩니다.
3. AI 성능은 반드시 적절한 기준선과 비교해서 말해야 합니다. ChatGPT 초안처럼 약한 기준만 두면 과장된 결론이 나옵니다.
4. 실제 기상청 예보는 수치예보모델(대기 물리 계산)과 넓은 지역의 관측을 씁니다. 그래서 한 지점의 기온 기록만으로는 급변을 예측할 수 없습니다.

## 자주 생기는 문제
| 증상 | 대응 |
|---|---|
| 1단계 `Drive 내려받기 실패` | 자동으로 GitHub 백업에서 읽으므로 그대로 진행합니다. 둘 다 실패하면 업로드 창에 Drive 폴더의 CSV를 올립니다. |
| 그래프 한글이 네모로 보임 | 0단계를 다시 실행합니다. 그래도 안 되면 `런타임 → 세션 다시 시작` 후 0단계부터 실행합니다. |
| `NameError` | 위 단계를 건너뛴 경우입니다. 0단계부터 순서대로 다시 실행합니다. |
| ZIP 이름이 `week11_학번_이름` | 11단계 `STUDENT`에 본인 정보를 넣지 않은 경우입니다. |

## 미검증
- 검증 환경에서는 Google Drive 접속이 막혀 있어, Drive(gdown) 경로는 Colab에서 실제로 실행해 보지 못했습니다. GitHub 백업 경로로는 끝까지 실행했고 오류 0건을 확인했습니다. 수업 전에 Colab에서 1단계를 한 번 실행해 `✔ [Google Drive]`가 나오는지 확인하세요.
