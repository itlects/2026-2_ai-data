# 데이터 사전

| 열 | 뜻 | 예시/단위 |
|---|---|---|
| month | 사용월 | 201701, 문자열로 읽기 |
| line | 호선 | 2호선 |
| station | 역명 | 강남 |
| hour | 시작 시각 | 8 = 08~09시, 0 = 00~01시 |
| boarding | 월 누적 승차 | 명(태그 집계) |
| alighting | 월 누적 하차 | 명(태그 집계) |
| calendar_days | 해당 월 달력일 | 28~31일 |
| boarding_per_day | 월 누적 승차/달력일 | 명/일, 해당 시간대 |
| alighting_per_day | 월 누적 하차/달력일 | 명/일, 해당 시간대 |

한 행은 한 달·한 호선·한 역·한 시간대다. 시간대 순서는 04시부터 다음 03시까지 표시한다. 00~03시 값은 원자료의 같은 사용월 값을 유지하며 날짜를 재구성하지 않는다. 결측은 0으로 대체하지 않는다.
