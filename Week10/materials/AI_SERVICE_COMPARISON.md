# 워크북 2. AI 혼잡도 예측 서비스 비교

## 만들 결과
워크북 1의 그래프 3개와 서울 실시간 도시데이터의 인구 전망을 비교해 한 페이지 결과표를 완성합니다. 실시간 사이트가 열리지 않아도 이 문서의 공식 매뉴얼 설명으로 비교를 마칠 수 있습니다.

- 수업 폴더: https://drive.google.com/drive/folders/1QAzK6zvNbnmODChS9MrjmB9AnERzdPgn

## 미리 준비한 서비스 설명
공식 매뉴얼 V8.5(2026.4), PDF 34번째 페이지의 실시간 인구 예측 설명을 기준으로 합니다. 최근 인구와 날짜·시간 특성으로 다음 12시간의 인구를 예상하는 Seq2Seq 모델을 소개합니다. 갑작스러운 행사 인파 변화에는 오차가 생길 수 있습니다. 지도상의 장소 인구를 대상으로 하며 열차 내부 탑승률과 다른 값입니다. 아래 표는 문서 기반 비교 예시이며 실제 서비스 예측값을 수집한 자료가 아닙니다.

| 항목 | 수업 데이터/그래프 | 실제 AI 서비스 |
|---|---|---|
| 목적 | 과거 이용 패턴 이해 | 향후 장소 인구 전망 |
| 입력 | 월·역·시간대별 승하차 통계 | 최근 인구, 날짜·시간 특성 |
| 공간 | 2호선의 선택한 역 | 서비스가 정의한 주변 영역 |
| 출력 단위 | 월 누적 명, 또는 달력일평균 명/일 | 장소의 시간별 인구·혼잡 전망 |
| 시간 | 2017년 12개월 | 조회 시점 이후 전망 |
| AI 역할 | 기본 그래프는 집계·시각화, 선택 모델은 이용량 학습 | 인구 시계열의 미래 변화 예측 |
| 오차 확인 | 선택 심화의 보류 기간 MAE | 같은 정의의 사후 관측값이 있어야 계산 가능 |

## 따라 하기
1. 워크북 1에서 만든 강남역 선그래프와 히트맵을 엽니다.
2. 서비스 지도에서 강남역을 검색하고 표시 영역을 확인합니다.
3. 인구 전망 화면에서 조회일시(KST), 자료 갱신시각, 예측 대상시각, 예상 인구/범위, 혼잡등급을 기록합니다. 표기되지 않은 항목은 '미제공'으로 적습니다.
4. 아래 표의 빈칸을 작성합니다. 접속 불가 시 관찰방식에 '매뉴얼 기반'으로 적고 수치 관측값은 '미조회'로 둡니다.
5. 수업 데이터와 서비스의 숫자를 직접 빼서 정확도를 계산하지 않습니다. 기간·공간·관측 대상이 다르기 때문입니다.

| 제출 항목 | 학생 기록 |
|---|---|
| 학번/이름/분반 | 작성 |
| 관찰 방식 | 실시간 조회 / 매뉴얼 기반 |
| 조회일시(KST)/장소 | 작성 |
| 자료 갱신시각/예측 대상시각 | 작성 또는 미조회 |
| 예측 인구/범위/혼잡등급 | 작성 또는 미조회 |
| 수업 그래프의 선택 월/역/승차 피크 | 그래프에서 작성 |
| 두 결과가 달라질 수 있는 이유 2가지 | 작성 |
| 출발 시각을 정할 때 활용하는 방법 | 작성 |
| 서비스 정확도를 평가하기 위한 추가 데이터 | 작성 |

## 답변 예시
2017년 월별 역 이용량과 오늘 역 주변 체류 인구는 시점과 관측 대상이 다릅니다. 과거의 저녁 승차 집중 패턴을 참고한 뒤, 방문 당일의 인구 전망을 추가로 확인할 수 있습니다. 서비스의 예측 정확도는 같은 장소·시각에 대해 미리 저장한 예측과 사후 관측을 짝지어 평가해야 합니다.

## 선택 AI 실습과 연결
Colab의 선택 심화에서는 1~9월로 학습하고 10~12월의 역·시간별 평균 승차 이용량을 예측합니다. 9월 값을 유지하는 기준 모델과 MAE를 비교합니다. 실제 서비스의 성능을 재현하거나 검증하는 실험이 아닙니다.
