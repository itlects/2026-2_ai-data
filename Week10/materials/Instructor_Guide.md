# 교수자 진행 가이드

## 기본 운영
기본 120분: 이론 25분 후 학생 Colab 1~7단계를 수행하고 9단계에서 저장합니다. 8단계 AI 학습은 추가 실습 또는 과제입니다. 학생용은 코드를 비워 두지 않았습니다. 학생은 조건을 변경하고 결과를 해석하며 답변을 완성합니다.

수업 전 노션·Drive 자료 폴더와 Colab 사본 만들기를 확인합니다. CSV 자동 읽기 실패 시 Drive 제공본 다운로드→업로드를 사용합니다. 원자료 CSV 대신 tidy CSV를 선택해야 합니다.

## 기준 실행 결과
- 1,728행×9열, 역 6개, 12개월, 결측 0, 중복키 0.
- 가공 전후 승차 합 154,371,043, 하차 합 153,495,465. 6역의 12개월 집계이며 서울 전체 인원이 아닙니다.
- 기본 201709·강남: 표본 역 중 승하차 활동량 최대는 강남. 승차 피크 18~19시 13,133.5명/일, 하차 피크 08~09시 12,353.8명/일.
- 그림: 역별 가로 막대, 선택역 승하차 선, 역×시간 승차 히트맵. 영문 표기는 강남=Gangnam, 잠실=Jamsil, 신림=Sillim, 신도림=Sindorim, 홍대입구=Hongik Univ., 시청=City Hall.
- 선택 예측: 1~9월 1,296행 학습, 10~12월 432행 평가. 9월 고정 기준 MAE 약 222.52명/일, Random Forest 약 219.82명/일. 버전별 소수점 차이가 가능하며 우열에 점수를 주지 않습니다.

## 질문 답변의 판단 기준
Q1·Q2: 선택한 조건에 맞는 숫자를 썼는지 확인합니다. 조건을 변경했다면 기본 예시와 다른 답도 정상입니다. Q3: 규모 비교와 시간 패턴의 차이를 설명합니다. Q4: 월별 집계·요일 부재·재차 인원 및 정원 부재를 설명합니다. Q5: 두 조건의 숫자나 시간대를 함께 적어야 합니다.

AI 서비스 비교는 실제 조회 또는 매뉴얼 기반을 명시해야 합니다. 매뉴얼 기반에서 현재 인구를 꾸며 적지 않았는지 확인합니다. 2017년 교통카드 집계와 지금 장소 인구 예측의 직접 정확도 비교는 허용되지 않습니다.

## 자주 발생하는 오류
| 현상 | 대응 |
|---|---|
| NameError | 런타임 초기화 뒤 1단계부터 순서대로 실행 |
| 데이터 크기/열 검사 실패 | tidy 제공 CSV인지 확인. 원자료 파일과 구별 |
| 자동 CSV 다운로드 실패 | Drive 파일 다운로드 후 셀의 업로드 창 사용 |
| 역 이름 검사 실패 | 2단계가 출력한 목록에서 복사, 괄호 포함 |
| 그래프가 이전 조건 | MONTH/STATION 수정 뒤 2~5단계 재실행 |
| 혼잡 서비스 연결 실패 | 미리 준비한 매뉴얼 기반 비교 문서 사용 |
| ZIP에 답변 안내가 남음 | 답변 셀 수정·재실행 후 9단계 재실행 |
| PNG 이름이 같아 덮어씀 | 최종 제출 조건의 그림이 저장되는 설계. 두 조건 비교 시 별도 사본 저장 |

## 검토 범위
9개 코드 셀과 선택 심화를 로컬 Python에서 실행했습니다. 원자료의 음수·누락·중복 및 합계 대조, 기본 그래프의 시각 검토를 수행했습니다. Colab 서버의 로그인·사본 저장 동작은 직접 확인하지 않았습니다. 공식 원자료 API 접근 실패로 공개 역사 보관본을 사용했으며 최신 자료로 대체하지 않았습니다.
