## 자주 나는 문제
| 증상 | 대응 |
|---|---|
| 그래프 한글이 네모 | 0단계를 다시 실행. 그래도 안 되면 `런타임 → 세션 다시 시작` 후 0단계부터 |
| `NameError: long` 등 | 앞 단계를 건너뜀 → 0단계부터 순서대로 실행 |
| 1단계에 `[GitHub 백업]` 표시 | Drive 다운로드가 일시 실패한 것. 같은 파일이므로 그대로 진행 |
| 1단계에서 업로드 창이 뜸 | Drive·GitHub 모두 실패한 경우. 노션 '실습 데이터' 링크에서 CSV 3개를 받아 하나씩 업로드 |
| 6단계 AssertionError | 역 이름 오타. 2단계 출력의 `지하철역` 그대로 입력(예: `잠실(송파구청)`) |
| 8단계 AssertionError | 혼잡도 자료는 1~8호선만. `CONG_LINE`은 숫자(2), 역은 괄호 없는 이름 |
| 12단계 AssertionError | 목록에 나온 파일을 만드는 단계를 다시 실행 |

## 해석 포인트
- 이용 인원(개찰구) ≠ 열차 혼잡(열차 안). 몽촌토성·강동구청은 이용은 적지만 앞 역에서 이미 탄 승객이 많아 혼잡.
- AI가 기준값보다 약간 좋을 뿐인 결과가 핵심: 입력에 혼잡의 원인(열차 안 인원)이 없으면 AI도 못 맞춘다 → 실제 서비스는 실시간 통신·열차 하중 데이터를 쓴다.
- 실시간 도시데이터 예측과 수업 데이터는 대상·단위·시점이 달라 직접 정확도 비교를 하지 않는다.
