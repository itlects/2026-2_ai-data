# 10주차 데이터 출처와 한계

## 1. 서울시 지하철 호선별 역별 시간대별 승하차 인원 정보 (OA-12252)
- 제공: 서울특별시 · 서울 열린데이터광장 https://data.seoul.go.kr/dataList/OA-12252/S/1/datasetView.do
- 사용 파일: `사용월 202609`(2026년 9월), `작업일자 20261003`, 621행 × 52열, 원본 인코딩 CP949
- 원본: `data/original/서울시 지하철 호선별 역별 시간대별 승하차 인원 정보_202609.csv`
  (SHA-256 52eac4028fbff7e07ab3f4e3f4dd79bbd16a2fd8a83803cbccf0c1612a8e03ca)
- 받은 경로: 자료 준비 환경에서 열린데이터광장 직접 접속이 차단되어, 열린데이터광장에서 내려받은 CSV를 수정 없이 보관한 공개 저장소
  `dante01yoon/seoul-live-3d` (커밋 37a6ab8, `data/raw/`)에서 복사했다. 저장소 README에 "열린데이터광장에서 내려받은 CSV를 그대로 저장, 내용은 고치지 않음"으로 명시되어 있고, 열 구성·작업일자·행 수가 공식 형식과 일치한다. 수업 전 강의자가 열린데이터광장에서 같은 달 파일을 내려받아 해시를 한 번 대조하면 완전하다.
- 학생용 `subway_hourly_202609.csv`: 인코딩만 UTF-8(BOM)으로 변환, 값·열 이름 변경 없음.
- 의미와 한계: 교통카드 태그 기준 한 달 합계(명). 같은 사람이 여러 번 셀 수 있고, 평일·주말이 섞여 있다. 열차 안 인원(혼잡도)은 알 수 없다. 서울시 집계 범위에 없는 노선(예: 신분당선)은 빠져 있다.
- 이용허락: 공공누리 제1유형(출처표시).

## 2. 서울교통공사 지하철 혼잡도 정보 (공공데이터포털 15071311)
- 제공: 서울교통공사 · https://www.data.go.kr/data/15071311/fileData.do (서울 열린데이터광장 OA-12928 연계)
- 사용 파일: `서울교통공사_지하철혼잡도정보_20250331.xlsx` (1~8호선, 평일/토요일/일요일 각 554행, 30분 단위 5시30분~00시30분)
  (SHA-256 3fd9943514afb7322fcea36ad4b04d4e86f7fd4f39176ed5d34fbc45f0bef726)
- 받은 경로: 공식 파일명을 그대로 보관한 공개 저장소 `JaeBinary/subway-congestion`(커밋 d7bb800, `data/input/`)에서 복사.
- 정의: 열차 정원 대비 탑승 인원 비율(%). 좌석이 모두 차면 34%, 정원이면 100%. 30분 동안 그 역을 지나는 열차 평균. 2024년부터 분기마다 갱신하며, 2025-12 기준 최신 파일은 20251130이다(이번 수업은 2025년 3월 기준 파일 사용).
- 한계: 축제·폭우·파업 같은 특수 상황, 실제 배차 차이는 반영되지 않는다. `00시30분` 열은 운행이 끝난 역이 많아 결측(1,108칸). 역번호 9000번대 행(성수·신도림·강동 지선 출발)은 같은 역명이 두 번 나와 실습에서 제외.
- 승하차 자료(2026년 9월)와 시점이 달라 9·10단계는 "패턴 비교"로만 해석한다.

## 3. 서울 실시간 도시데이터 (AI 인구·혼잡도 예측 서비스)
- 서비스: https://data.seoul.go.kr/SeoulRtd/ · 안내 https://data.seoul.go.kr/dataVisual/seoul/guide.do
- 내용: KT 통신 신호 기반 장소 실시간 인구, 혼잡도 4단계(여유·보통·약간 붐빔·붐빔), 향후 12시간 예측 인구(서울시 보도자료 2023-06-26), 2026년 기준 121장소.
- `citydata_places_121.csv`: 서울시가 배포한 「서울시 주요 121장소 목록.xlsx」를 UTF-8 CSV로 변환. 받은 경로는 1번과 같은 저장소 `data/raw/citydata/`.
- 비교 시 주의: 역 주변 '장소'의 체류 인구이며 열차 혼잡도나 개찰구 태그 수와 단위·대상이 다르다. 숫자를 직접 빼서 정확도를 계산하지 않는다.
