# 데이터와 출처

## 실습용 실제 이용량 데이터
- 원 제공기관: 서울특별시. 서울 열린데이터광장 「서울시 지하철 호선별 역별 시간대별 승하차 인원 정보」 OA-12252.
- 원 데이터 안내: https://data.seoul.go.kr/dataList/OA-12252/S/1/datasetView.do
- 수집 경유지: https://github.com/djagusgh/subway/blob/master/subway_2017.csv
- 경유 파일 Git blob SHA: 247bfb0595101e6a1fe45d38118c9a4a46876783. 해당 저장소 README는 서울시 Open API에서 2017년 월별 데이터를 수집했다고 설명한다.
- 확보일: 2026-11-05 (한국 기준). 공식 API/직접 다운로드는 작업 환경에서 연결되지 않아 공개 보관본을 사용했다. 공식 원본과의 전수 대조는 수행하지 못했다.
- 범위: 2017년 1~12월, 2호선 시청·잠실(송파구청)·강남·신림·신도림·홍대입구. 72개 역-월 기록, 24시간 변환 후 1,728행. 교육용 목적표집이며 서울 전체를 대표하지 않는다.
- subway_2017_selected_raw.csv: 보관본에서 해당 72행만 선택. 첫 열은 원 파일의 행 인덱스이며 분석용 역ID가 아니다.
- subway_2017_tidy.csv: 열 이름 정리, 시간별 세로 변환, 달력일 수로 나눈 일평균 추가. 결측/음수/중복 검증 및 원 승하차 합계 대조를 수행했다.
- 서울시 안내의 현재 이용허락: 공공누리 1유형(출처표시). 보관본 작성자의 분석 코드·그림은 복제하지 않았다. 강의 코드와 결과 그림은 이번 자료에서 새로 작성했다.
- 단위: boarding/alighting은 해당 월·역·시간대 누적 태그 건수(인원 통계). 개인 수가 아니며 승차+하차 합계에는 동일인의 이동이 중복 포함될 수 있다.
- boarding_per_day/alighting_per_day: 월 누적 ÷ 해당 월 달력일 수. 실제 특정 날짜/평일의 관측값이 아니다. 월별 자료에는 날짜·요일·날씨·열차·방향·차량 정원 정보가 없다.
- 현재 혼잡도·승강장 밀도·열차 탑승률로 사용할 수 없으며 최신 이용량으로 제시해서는 안 된다.

## 비교하는 실제 AI 서비스
- 서울 실시간 도시데이터: https://data.seoul.go.kr/SeoulRtd/
- 안내: https://data.seoul.go.kr/dataVisual/seoul/guide.do
- 매뉴얼 V8.5(2026.4): https://data.seoul.go.kr/SeoulRtd/downloads/실시간_도시데이터_매뉴얼.pdf
- PDF 34쪽(파일의 34번째 페이지), 「6 실시간 인구 예측」: 최근 인구와 날짜·시간 정보를 이용하는 Seq2Seq 방식의 향후 12시간 예측을 설명한다. 급격한 행사 인파 등에는 오차가 날 수 있다.
- 비교 대상은 역 주변 장소의 인구 예측이다. 지하철 차량 내부 혼잡도 예측과 구별한다. 이번 수업 모델은 월별 평균 승차 이용량을 예측하며 공식 서비스의 모델을 재현하지 않는다.
- 서비스 예측값과 2017년 월별 이용량은 기간·단위·공간·목표가 달라 직접 MAE를 계산하지 않는다. 실제 서비스 정확도 평가는 동일 시점/장소의 예측 저장본과 이후 관측값이 필요하다.
