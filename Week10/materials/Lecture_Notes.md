# 10주차. 교통 데이터의 시각화

인공지능과 데이터 활용 · 동서울대학교 · 기본 수업 120분

## 이번 시간의 문제
같은 2호선 역이라도 사람이 많이 타고 내리는 시간은 왜 다를까요? 서울시 교통카드 이용 통계를 시각화해 역별·시간대별 차이를 찾고, AI가 제공하는 혼잡 전망과 어떤 점이 다른지 설명합니다.

## 학습 목표
1. 공개 교통 데이터의 한 행·기간·단위를 설명한다.
2. pandas로 조건을 선택하고 역별 합계와 시간대별 표를 만든다.
3. 막대·선·히트맵을 목적에 맞게 선택하고 제목·축·단위·범례를 넣는다.
4. 월별 이용량, 실제 혼잡도, AI 예측을 구분하고 결과의 한계를 설명한다.
5. 숫자와 그림을 근거로 이동 계획을 제안한다.

## 1. 교통 데이터가 알려 주는 것
교통카드 태그를 집계하면 역과 시간별 이용량을 볼 수 있습니다. 한 행의 의미를 먼저 확인해야 합니다. 이번 데이터는 '한 달·한 호선·한 역·한 시간 구간'입니다. 2017년 2호선 6역의 12개월을 교육용으로 선택했습니다. 역사 보관본이며 현재 수요를 나타내지 않습니다.

승차는 교통수단 이용을 시작하는 태그 집계, 하차는 끝내는 태그 집계입니다. 승차와 하차를 더하면 역의 이용 활동량을 볼 수 있지만 중복 없는 사람 수나 열차 안 승객 수로 해석할 수 없습니다.

월의 길이가 다르면 같은 하루 이용 수준이어도 월 누적은 달라집니다. 그래서 월 누적/달력일로 평균을 계산합니다. 이 평균에는 주말과 공휴일도 포함됩니다. 요일 정보가 없으므로 평일만 따로 추정하지 않습니다.

## 2. 데이터를 시각화하는 과정
질문 설정 → 데이터와 출처 확인 → 행·열·결측·중복 검사 → 조건 선택 → 집계 → 그래프 → 해석과 한계 기록 순서로 진행합니다.

| 함수/용어 | 의미 | 이번 실습 |
|---|---|---|
| DataFrame | 행·열 형태 데이터 | df |
| read_csv | CSV 읽기 | month를 문자열로 유지 |
| 결측값 | 관측 또는 값이 없음 | isna로 검사, 임의로 0 처리하지 않음 |
| 키 | 행을 구분하는 열 조합 | month+line+station+hour |
| groupby | 그룹별 묶기 | 역별 일평균 합계 |
| pivot | 행·열의 교차표 | 역×시간 승차표 |
| reindex | 원하는 순서로 재배치 | 04~23,00~03 |
| 표본 | 전체에서 선택한 일부 | 2호선 6역, 대표 표본 아님 |

## 3. 질문에 맞는 그래프 고르기
| 질문 | 그래프 | 읽을 때 확인할 것 |
|---|---|---|
| 어느 역의 이용 활동이 큰가? | 가로 막대 | 0에서 시작하는 축, 정렬, 명/일 |
| 같은 역의 승차·하차는 언제 집중되나? | 선그래프 | 시간 순서, 두 선의 범례, 월 범위 |
| 역과 시간을 동시에 비교하려면? | 히트맵 | 모든 역에 같은 색 기준, 색 범례 |

0시부터 무조건 정렬하면 야간 운행 흐름이 분리됩니다. 이번 그림은 04시부터 다음 03시 순서로 표시합니다. 월 단위 집계값이므로 실제 날짜를 이동시키지는 않습니다. 히트맵에서 색이 진하다는 것은 이용량이 많다는 뜻이며 '위험' 판정이 아닙니다.

## 4. 이용량과 혼잡도 구분
혼잡도를 계산하려면 무엇이 어디에 얼마나 모여 있는지와 공간·수용량을 알아야 합니다. 월별 역 태그 수만으로는 특정 열차의 재차 인원, 승강장의 제곱미터당 인원, 정원 대비 탑승률을 구할 수 없습니다.

| 값 | 분자/단위 | 추가로 필요한 것 |
|---|---|---|
| 월 승차량 | 태그 집계 명/월 | 이번 자료에 존재 |
| 시간대별 일평균 | 해당 시간 월 누적/달력일 | 이번 자료에서 계산 |
| 승강장 밀도 | 체류 인원/면적 | 동일 시각 체류 인원과 면적 |
| 차량 탑승률 | 재차 인원/차량 정원 | 열차·방향·정원·재차 인원 |
| 장소 혼잡 전망 | 정의된 영역의 미래 인구·등급 | 최근 인구 시계열과 예측 모델 |

## 5. AI는 무엇을 하나요?
기본 과정의 집계와 그래프는 사람이 정한 규칙에 따라 계산합니다. 선택 심화의 Random Forest는 과거 입력과 이용량의 관계를 학습해 보지 않은 기간의 이용량을 예상합니다. AI가 있다고 정확도가 자동으로 높아지는 것은 아닙니다.

학습 데이터와 평가 데이터를 시간 순으로 분리합니다. 미래 이용량을 학습에 넣으면 아직 알 수 없는 정보를 사용하게 됩니다(데이터 누수). 이번에는 1~9월로 학습하고 10~12월 전체를 보류합니다. 9월 수준을 유지하는 간단한 방법도 함께 평가합니다.

MAE = 예측과 관측 차이의 절댓값을 평균한 값입니다. 단위는 목표와 같은 명/일이며 0에 가까울수록 오차가 작습니다. 1년 자료의 작은 차이를 실제 서비스의 우열로 일반화하지 않습니다.

## 6. 실제 AI 서비스와 비교
서울 실시간 도시데이터의 인구 전망을 비교 대상으로 사용합니다. 해당 서비스는 지도상의 장소 인구를 다룹니다. 공식 매뉴얼 V8.5의 실시간 인구 예측 설명을 읽고 입력·공간·기간·출력·한계를 비교합니다. 읽기 요약과 기록 양식은 AI_SERVICE_COMPARISON.md에 미리 준비되어 있습니다.

같은 역 이름이라도 교통카드 태그 장소와 주변 인구 영역은 다릅니다. 과거 월별 통계와 현재 미래 전망을 직접 빼서 정확도를 계산할 수 없습니다. 서비스 정확도를 확인하려면 같은 장소·시각·정의의 예측 저장값과 이후 관측값이 필요합니다.

## 8. 확인 문제
1. 월 누적 승차량을 30으로 나누는 것이 모든 달에 적합할까요? 실제 달력일 수가 필요합니다.
2. 강남역 18시 승차 피크는 특정 열차가 가장 혼잡하다는 증거인가요? 월 평균 태그 수이므로 확정할 수 없습니다.
3. 히트맵을 역마다 최대값으로 정규화하면 무엇이 달라질까요? 역 내부 패턴은 보이지만 역 사이 절대량 비교가 어려워집니다.
4. 평가할 10월 값을 학습에 넣어도 될까요? 9월 말 예측 설정에서는 미래 정보가 되어 사용할 수 없습니다.
5. 서울시 인구 전망과 수업 예측값의 MAE를 계산해 우열을 정할 수 있을까요? 대상·기간·단위가 달라 불가능합니다.
