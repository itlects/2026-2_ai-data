# 7주차 데이터 출처 · 정제 규칙 · 사용 조건

두 자료 모두 공개 라이선스 말뭉치이며 API 키 없이 내려받을 수 있다. `tools/build_week07_data.py`가 원자료에서 아래 규칙으로 표본을 만든다(시드 2026, 다시 실행해도 MD5가 같다).

## 1. 댓글 — `week07_comments_300.csv`
| 항목 | 내용 |
|---|---|
| 원자료 | NSMC(Naver Sentiment Movie Corpus) `ratings.txt` — 네이버 영화 140자평 200,000건 |
| 배포처 | https://github.com/e9t/nsmc |
| 라이선스 | **CC0 1.0** (퍼블릭 도메인 기증, 저장소 README 확인 2026-10-15) |
| 라벨 | 원 평점 1~4점 = 부정(0), 9~10점 = 긍정(1). 5~8점은 배포자가 제외 |
| 원자료 MD5 | `f1f2772629b775ac39a6344e95a2c9a8` (압축 해제 `ratings.txt`) — 저장소 `nsmc_ratings.txt.gz`는 내용 그대로 gzip만 한 미러 |

**정제·추출 규칙**
1. 앞뒤 공백 제거, 연속 공백 1칸, 유니코드 NFC 정규화
2. 같은 문장이 2번 이상 나오면 **모두 제외**
3. 개인정보·외부 링크 형태 제외: 전화번호 형태 숫자, `@`, `http`, `www.`, `.com`, 영문+숫자 아이디 형태
4. 수업 화면에 띄우기 부적절한 표현 목록(욕설·성적·혐오·비하, 원자료의 `OO` 가림표, 주변 인물 언급)이 들어간 문장 제외 — 목록은 빌드 스크립트 `BLOCK_WORDS`
5. 길이 10~140자 → 후보 **173,931건**
6. 후보를 섞은 순서(시드 2026)에서 **강의자가 직접 읽고 뺀 25건**(`tools/week07_comment_exclude.csv`, 사유 기록)을 제외하고 긍정·부정 각 150건 → **300건**

| 열 | 설명 |
|---|---|
| `comment_id` | C001~C300 (수업용 번호) |
| `src_id` | 원자료 id (출처 추적용) |
| `sentiment` | 긍정 / 부정 (원 평점 기준 참고 라벨) |
| `text` | 댓글 원문 (맞춤법·줄임말·이모티콘 그대로) |

## 2. 뉴스 — `week07_news_350.csv`
| 항목 | 내용 |
|---|---|
| 원자료 | KLUE-YNAT v1.1 `ynat-v1.1_train.json` — 연합뉴스 기사 **제목** 45,678건, 7개 분야 |
| 배포처 | https://github.com/KLUE-benchmark/KLUE (klue_benchmark/ynat-v1.1) |
| 라이선스 | **CC BY-SA 4.0** — 출처 표시, 변경 시 같은 조건으로 공유. 이 표본과 `ynat_titles_all.csv.gz`도 CC BY-SA 4.0 |
| 원 출처 | 연합뉴스(네이버 뉴스 경유) 2016~2019년 기사 제목. 분야 라벨은 KLUE 작업자가 붙임 |
| 원자료 MD5 | `367c4468489e56c806a1c6ee9d0a55f6` |

**정제·추출 규칙** 공백 정리·유니코드 NFC 정규화(원자료의 호환용 한자 `女`(U+F981)를 일반 `女`(U+5973)로 통일 — N248) → 같은 제목 중복 모두 제외 → 10자 이상 → 후보 45,499건 → 분야(정치·경제·사회·생활문화·세계·IT과학·스포츠)별 50건 무작위(시드 2026) → **350건**

| 열 | 설명 |
|---|---|
| `news_id` | N001~N350 |
| `category` | KLUE 분야 라벨 |
| `title` | 기사 제목 (KLUE가 따옴표 등 일부 기호를 지운 형태 — `…종합`, `1보`가 붙어 보임) |
| `date` | 기사 날짜 (YYYY-MM-DD) |
| `url` | 네이버 뉴스 주소 (일부는 삭제됐을 수 있음) |
| `guid` | KLUE 원자료 id |

`ynat_titles_all.csv.gz`: 원자료 45,678건 전체의 `guid·category·title·date·url` (확장 과제: 연도별·분야별 비교용).

## 3. 한계 — 학생에게 꼭 알릴 것
- 댓글은 **유튜브 댓글이 아니라 영화 한 줄 평**이다(형태는 같음: 짧은 구어체, 줄임말, ㅋㅋ). 실제 유튜브 댓글은 `colab/Week07_00_유튜브댓글수집.ipynb`로 직접 모은다(API 키 필요).
- 뉴스는 **본문이 없는 제목**뿐이고 2016~2019년 자료다. 요즘 뉴스와 주제가 다르다.
- 감성 라벨은 평점에서 온 것이라 문장과 어긋나는 경우가 있다(예: 부정 라벨인데 "it is fantastic").
- 부적절 표현은 목록·직접 읽기로 걸렀지만 완벽하지 않다. 발견하면 `week07_comment_exclude.csv`에 추가하고 빌드 스크립트를 다시 실행한다(그 감성의 다음 후보 한 건만 바뀌고, 번호 C001~ 순서는 다시 섞인다).
- 원문을 재배포할 때는 위 라이선스(특히 뉴스 CC BY-SA 4.0 출처 표시)를 따른다.
