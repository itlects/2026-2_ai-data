## 반드시 읽을 것 — 중간고사 수행평가 문제 지시문

**문제:** 여러분은 생활 서비스(배달·음식·상담·교육)의 고객 경험을 분석하는 데이터 분석 담당자입니다. 제공된 `midterm_reviews.csv`를 Google Colab에서 읽어 데이터 오류를 정리하고, **① 서비스별 고객평점 비교표 ② 월별 만족도 변화 선그래프 ③ 서비스별 평균평점 막대그래프 ④ 리뷰 감성분류 결과와 별점의 비교표 ⑤ 긍정·부정 단어 빈도표 및 그래프**를 작성하십시오. 마지막으로 자신의 실행 결과를 증거로 여섯 개 질문에 답하고 개선 의견을 제안하십시오.

**무엇을 해야 하나요?** 기본 예시 코드를 C1→C6 순서로 실행하고, 각 단계의 '학생이 완성할 내용'을 채웁니다. 결과에서 수치와 그래프를 확인한 뒤 문제 D15~D20에 답합니다. 실행만 하고 해석을 비워 두면 해당 해석 점수를 받을 수 없습니다.

**완성 결과의 모습(아래는 형식 예시일 뿐 정답 수치가 아님):**
```text
[원자료 확인]       (행 수, 열 수), 처음 5행, 열 자료형
[데이터 정제]       정제 전 n건 → 정제 후 m건 / 제거 사유와 건수
[서비스별 집계표]   category | review_count | mean_rating
[월별 선그래프]     X축 월(YYYY-MM), Y축 월별 평균 별점(1~5)
[서비스별 막대]     X축 배달·음식·상담·교육, Y축 평균 별점
[감성 비교표]       실제 별점 긍정/부정 × 규칙 판정 긍정/부정/미판정
[단어 빈도]        긍정 단어 TOP10, 부정 단어 TOP10, 빈도 막대그래프
[결과 보고서]      데이터 근거가 있는 답변 6개 및 AI 활용 기록
```

**제출물:** 학번_성명_중간고사.ipynb(코드와 출력 저장), 학번_성명_답안.pdf(A·B·D 문항), `category_summary.csv`, `sentiment_crosstab.csv`, 긍정/부정 단어 빈도 CSV, 그림 PNG 최소 3개(월별·서비스별·단어 빈도), 출처 및 AI 사용 내역. 기한은 별도 수업 공지를 따릅니다.

**작업 순서:** [Colab 노트북 열기](https://colab.research.google.com/github/itlects/2026-2_ai-data/blob/main/Week08_Midterm/colab/Midterm_Student.ipynb) → 파일 > Drive에 사본 저장 → 코드 셀 위에서부터 순서대로 실행(Shift+Enter) → TODO·해석 문장 작성 → 런타임 > 모두 실행으로 재확인 → 파일 내려받기 및 제출. 연결이 끊기면 [CSV 파일](https://drive.google.com/file/d/1JqljnmwH9veWBvXp3thT5Pie-dYa6KCO/view?usp=drivesdk)을 직접 다운로드하여 Colab의 파일 영역에 업로드합니다.

**평가 기준:** 결과 파일 존재 여부만 보는 것이 아니라, 데이터 정제 근거, 표·그래프 값, 감성 규칙의 설명, 결과 해석을 항목별로 채점합니다. 표에 있는 실제 값은 여러분이 프로그램을 실행해 직접 확인해야 합니다.

### 단계별로 예상할 수 있는 화면과 확인 항목

| 단계 | 예상 출력 형식 | 학생이 확인/작성할 부분 |
|---|---|---|
| C1 데이터 읽기 | `(행 수, 5)` 및 `review_id, date, category, rating, review_text` 5개 열 표시 | 5개 열의 의미 설명 |
| C2 데이터 정제 | 열별 결측 건수, ID 중복 건수, 정제 전후 건수 | 제거 기준과 제거 건수 |

3. 3개월 이동평균을 사용하는 주요 목적은? ① 모든 값 제거 ② 변동을 완화해 추세 확인 ③ 원인 확정 ④ 데이터 암호화
4. 관측된 두 변수의 상관계수가 0.8일 때 옳은 설명은? ① 인과관계 확정 ② 대체로 양의 선형관계 ③ 항상 예측 정확도 80% ④ 표본 오차 없음

7. 원자료가 날짜 내림차순이면 이동평균 이전에 먼저 할 일은? ① 날짜 오름차순 정렬 ② 무작위 재배열 ③ 인덱스 삭제만 ④ 결측값 임의 입력

## C. 수행과제: 생활 서비스 리뷰 데이터 분석 (42점)
주어진 `midterm_reviews.csv`를 제공된 `Midterm_Student.ipynb`에서 읽어 분석하시오. 필드: review_id, date, category, rating, review_text. 학번으로 데이터를 변경하거나 임의로 제거하지 말 것. 결과의 출처는 '시험용 합성 데이터'로 표시.
- C1 (6점) 파일 로딩·열/행수·자료형·최초 5행 출력 (각 1.5점).
- C2 (8점) 결측/중복 건수 표, 결측 리뷰 제거, review_id 중복 제거, 날짜 변환, 정제 전후 건수 기록 (각 2점).
- C3 (6점) category별 리뷰 수·평균 별점 집계 표 (각 3점).
- C4 (8점) 월별 평균 별점 추세선, category별 평균 별점 막대그래프; 제목·축·범례/라벨 명시 (각 4점).
- C5 (8점) 긍정/부정 단어 목록을 학생이 직접 정하고 단어 등장 기반 감성 분류, 별점(4·5 긍정 / 1·2 부정 / 3 중립)과의 교차표, 일치율 산출 (규칙 설명 2점, 분류 3점, 표+일치율 3점). 중립과 규칙 미판정은 정확도 분모에서 제외하고 제외 건수를 명시할 것.
- C6 (6점) 감성별 빈도 상위 10단어 표 1개와 막대그래프 1개 생성; 불용어 목록 및 토큰화 기준 설명 (표 2점, 그래프 2점, 방법 설명 2점).
