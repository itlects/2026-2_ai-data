평가범위: 1~7주차. 총 100점. 제출: 답안 PDF + 실행완료 Colab .ipynb + 분석결과 CSV + 그래프 2개. 학생별 학번과 성명을 파일명에 포함. 제출 기한은 수업 공지에서 확인. 공개된 자료와 AI 활용은 허용하되 사용 도구·프롬프트·검증 내용을 명시하며, 결과만 복사한 답안은 감점한다.

## 배점
- A 객관식 10문항 × 2점 = 20점

## A. 객관식 (각 2점, 정답 하나)
1. 데이터 수집 후 분석 전에 우선 확인할 항목으로 가장 적절한 것은? ① 파일 이름만 ② 데이터 출처·시점·결측·중복 ③ 시각화 색상 ④ AI 요약 길이
2. pandas의 `df.isna().sum()` 기능은? ① 평균 ② 결측 개수 ③ 상관계수 ④ 중복 삭제
3. 3개월 이동평균을 사용하는 주요 목적은? ① 모든 값 제거 ② 변동을 완화해 추세 확인 ③ 원인 확정 ④ 데이터 암호화
4. 관측된 두 변수의 상관계수가 0.8일 때 옳은 설명은? ① 인과관계 확정 ② 대체로 양의 선형관계 ③ 항상 예측 정확도 80% ④ 표본 오차 없음
5. 박스플롯의 IQR은? ① 평균-중앙값 ② 최댓값-최솟값 ③ Q3-Q1 ④ 분산/표준편차
6. 일별 종가로 수익률을 계산할 때 올바른 식은? ① 현재/전일-1 ② 현재+전일 ③ 현재×전일 ④ 전일-현재
7. 원자료가 날짜 내림차순이면 이동평균 이전에 먼저 할 일은? ① 날짜 오름차순 정렬 ② 무작위 재배열 ③ 인덱스 삭제만 ④ 결측값 임의 입력
8. 상품리뷰 감성분석에서 별점 라벨의 한계는? ① 모든 리뷰 정답 보장 ② 별점과 문장의 감정 불일치 가능 ③ 텍스트 불필요 ④ 오분류 불가능
9. TF-IDF가 빈도 계산과 다른 점은? ① 문서 전체에서 흔한 단어를 무조건 강조 ② 문서별 특징적인 단어에 상대적 가중치 ③ 이미지 픽셀 변환 ④ 날짜 정렬
10. AI 분석 결과의 올바른 검증 방법은? ① 출처 없이 수용 ② 데이터 표와 원문 근거에 대조 ③ AI가 말한 원인을 사실로 단정 ④ 그래프 생략

## B. 주관식 (각 5점)
11. 결측값·중복값·이상값 각각의 의미와 처리할 때 주의점을 1문장씩 설명하시오.
12. 이동평균과 선형회귀 추세선의 차이를 쓰고, 둘 다 경제적 원인을 입증하지 못하는 이유를 설명하시오.
13. 금융 데이터 분석에서 일간수익률과 변동성의 차이를 설명하고, 이를 투자 매수 추천으로 단정해서는 안 되는 이유를 쓰시오.
14. 키워드 규칙 기반 감성분석과 AI 분류의 장단점을 비교하고, AI 요약의 근거를 검증하는 절차 2가지를 서술하시오.

## C. 수행과제: 생활 서비스 리뷰 데이터 분석 (42점)
주어진 `midterm_reviews.csv`를 제공된 `Midterm_Student.ipynb`에서 읽어 분석하시오. 필드: review_id, date, category, rating, review_text. 학번으로 데이터를 변경하거나 임의로 제거하지 말 것. 결과의 출처는 '시험용 합성 데이터'로 표시.
- C1 (6점) 파일 로딩·열/행수·자료형·최초 5행 출력 (각 1.5점).
- C2 (8점) 결측/중복 건수 표, 결측 리뷰 제거, review_id 중복 제거, 날짜 변환, 정제 전후 건수 기록 (각 2점).
- C3 (6점) category별 리뷰 수·평균 별점 집계 표 (각 3점).
- C4 (8점) 월별 평균 별점 추세선, category별 평균 별점 막대그래프; 제목·축·범례/라벨 명시 (각 4점).
- C5 (8점) 긍정/부정 단어 목록을 학생이 직접 정하고 단어 등장 기반 감성 분류, 별점(4·5 긍정 / 1·2 부정 / 3 중립)과의 교차표, 일치율 산출 (규칙 설명 2점, 분류 3점, 표+일치율 3점). 중립과 규칙 미판정은 정확도 분모에서 제외하고 제외 건수를 명시할 것.
- C6 (6점) 감성별 빈도 상위 10단어 표 1개와 막대그래프 1개 생성; 불용어 목록 및 토큰화 기준 설명 (표 2점, 그래프 2점, 방법 설명 2점).

## D. 결과 해석 (각 3점)
15. 정제 전후 리뷰 건수와 제거 이유를 구체적 숫자로 적으시오.
16. 가장 평균 평점이 높은 category를 수치와 함께 적고, 표본 크기가 작은 집단의 해석상 주의점을 쓰시오.
17. 월별 평균 평점이 가장 높았던 월·가장 낮았던 월을 제시하고, 그래프 근거로 최근 방향을 서술하시오.
18. 규칙 기반 감성 결과와 별점 라벨이 서로 다른 리뷰 한 건(review_id)을 제시하고 불일치 이유를 추정하시오.
19. 감성별 상위 단어 결과에서 확인한 차이 1개와 워드클라우드·빈도 분석의 한계 1개를 설명하시오.
