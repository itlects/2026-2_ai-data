**무엇을 해야 하나요?** 기본 예시 코드를 C1→C6 순서로 실행하고, 각 단계의 '학생이 완성할 내용'을 채웁니다. 결과에서 수치와 그래프를 확인한 뒤 문제 D15~D19에 답합니다. 실행만 하고 해석을 비워 두면 해당 해석 점수를 받을 수 없습니다.

**완성 결과의 모습(아래는 형식 예시일 뿐 정답 수치가 아님):**
```text
[원자료 확인]       (행 수, 열 수), 처음 5행, 열 자료형
[데이터 정제]       정제 전 n건 → 정제 후 m건 / 제거 사유와 건수
[서비스별 집계표]   category | review_count | mean_rating
[월별 선그래프]     X축 월(YYYY-MM), Y축 월별 평균 별점(1~5)
[서비스별 막대]     X축 배달·음식·상담·교육, Y축 평균 별점
[감성 비교표]       실제 별점 긍정/부정 × 규칙 판정 긍정/부정/미판정
[단어 빈도]        긍정 단어 TOP10, 부정 단어 TOP10, 빈도 막대그래프
[결과 보고서]      데이터 근거가 있는 답변 5개 및 AI 활용 기록
```

## C. 수행과제: 생활 서비스 리뷰 데이터 분석 (40점)
제공된 `midterm_reviews.csv`와 `Midterm_Student.ipynb`를 이용해 순서대로 수행합니다. 데이터는 시험용 합성 데이터이며, 원자료를 임의로 변경하지 마십시오. Notion 문제지문에 CSV 원본과 그래프 예시 그림이 직접 첨부되어 있습니다.

**C1. 데이터 불러오기 (5점)**
- CSV를 읽고 데이터 크기(행 수·열 수) 출력 (2점)
- 열 이름·자료형과 첫 다섯 행 표시 (2점)
- 제공된 다섯 필드의 의미를 설명 (1점)
- 예상 화면: `(행 수, 5)` 및 다섯 열의 미리보기 표

**C2. 데이터 전처리 (5점)**
- 결측·공백 리뷰 건수, 중복 ID 건수 확인 (2점)
- 공백·결측 리뷰 제거, 중복 ID 제거 및 날짜 변환 (2점)
- 정제 전후 건수 및 제거 기준 기록 (1점)
- 예상 화면: 원자료 건수, 결측/중복 통계, 정제 후 건수

**C3. 서비스 범주별 집계 (5점)**
- `category`별 리뷰 수 집계 (2점)
- 평균 `rating` 계산 (2점)
- 표로 제시하고 CSV 저장 (1점)
- 예상 화면: `category | review_count | mean_rating` 4행 표

**C4. 그래프 생성 (10점)**
- 월별 평균 평점 선그래프 (4점)
- 서비스별 평균 평점 막대그래프 (4점)
- 두 그래프의 제목, 축·단위, 저장 파일 (2점)
- 예상 화면: 월별 선그래프 1개와 서비스별 막대그래프 1개

**C5. 감성 분류 및 검증 (10점)**
- 긍정·부정 키워드 규칙을 직접 수정(최소 2개)하고 선정 이유 설명 (3점)
- 리뷰별 감성을 긍정·부정·미판정으로 분류 (2점)
- 별점 기반 감성(4·5 긍정, 1·2 부정, 3 중립)과의 교차표 (3점)
- 중립·미판정 제외 건수 및 일치율 계산 (2점)
- 예상 화면: 별점 감성 × 규칙 감성 교차표, 제외 건수와 일치율

**C6. 단어 빈도 분석 (5점)**
- 토큰화 및 불용어 처리 기준 설명 (1점)
- 긍정/부정 그룹별 상위 10개 단어 빈도표 생성 (2점)
- 단어 빈도 막대그래프 생성 (2점)
- 예상 화면: 빈도표 2개와 빈도 그래프 1개 이상

## D. 수행 결과 해석 (5문항 × 4점 = 20점)
**15번 (4점).** 정제 전후 리뷰 건수를 제시하고, 어떤 자료가 왜 제거되었는지 숫자로 설명하시오. (전후 건수 2점 + 제거 이유 2점)

**16번 (4점).** 평균 별점이 가장 높은 서비스 분야와 평균값·리뷰 수를 제시하고, 표본 수를 고려한 해석상 주의점 한 가지를 설명하시오. (수치 및 분야 2점 + 해석 2점)

**17번 (4점).** 월별 평균 별점이 가장 높은 달과 낮은 달을 수치로 제시하고, 월별 그래프를 근거로 기간별 변화 추세를 설명하시오. (최고·최저 월과 값 2점 + 그래프 해석 2점)

**18번 (4점).** 키워드 감성분류와 별점 분류가 서로 다른 리뷰 1건의 `review_id`와 원문을 제시하고, 차이가 생긴 이유를 설명하시오. (사례 2점 + 원인 해석 2점)

**19번 (4점).** 긍정·부정 리뷰에서 상위 단어의 차이 한 가지를 설명하고, AI 또는 본인의 해석문 한 문장을 제시하시오. 그 해석에서 **데이터로 검증 가능한 사실**과 **추정에 불과한 주장**을 각각 구분하시오. (단어 비교 1점 + 해석문 1점 + 사실/추정 구분 2점)
