# 워크북 0 — 공개 감성데이터 수집 및 원자료 확인
**주제:** 데이터 수집은 분석보다 앞선 과정입니다. **실습 시간:** 약 30~40분 (기존 180분 내 포함하려면 후속 실습 시간 조정)

## 학습 목표
- 수집 목적·출처·허용 범위·수집일·데이터 유형을 기록한다.
- 공개 파일을 직접 내려받고 Colab에서 데이터 구조를 확인한다.
- 누락값·중복·라벨 분포 확인 후 100건을 추출한다.
- 원본/분석용 데이터를 별도로 보관한다.

## 감성데이터 수집 방법
1. **공개 파일 다운로드**: 저작권·이용 조건을 먼저 확인하고 배포자가 제공한 파일을 받는다. 이번 실습의 기본 방법.
2. **공식 API**: 인증키·호출 제한·제공 필드·서비스 약관 확인. 가능한 경우 향후 프로젝트에서 사용.
3. **설문/직접 작성**: 동의를 받은 응답만 수집하며 개인정보를 배제한다. 출처와 표본편향을 기록한다.
4. **웹 크롤링**: 서비스 약관·robots·법적 허용 여부 확인 후 적법한 범위에서만 진행. 본 실습에서는 사용하지 않음.

## 실제 공개 데이터 소개
- [NSMC 공개 저장소](https://github.com/e9t/nsmc): 네이버 영화 리뷰 20만 건. 학습용 15만/시험용 5만. CSV가 아니라 탭 구분 텍스트(TSV)이며 열은 `id/document/label`. label 0=부정, 1=긍정. 중립 제외. **쇼핑몰 리뷰는 아님.**
- [학습 원자료 직접 다운로드](https://raw.githubusercontent.com/e9t/nsmc/master/ratings_train.txt)
- [검증용 원자료 직접 다운로드](https://raw.githubusercontent.com/e9t/nsmc/master/ratings_test.txt)
- [수집 Colab 바로 열기](https://colab.research.google.com/github/itlects/2026-2_ai-data/blob/main/Week06/notebooks/Week06_00_collect_public_sentiment.ipynb)
- [6주차 수업용 합성 쇼핑 리뷰](https://github.com/itlects/2026-2_ai-data/blob/main/Week06/data/shop_reviews_synthetic_120.csv): 앞선 워크북 1~4에 사용, 실제 온라인 고객 수집 자료와 구분.
- [AI Hub 데이터 안내](https://aihub.or.kr/): 계정·신청 및 개별 데이터 이용조건을 확인하는 심화 선택 경로.

## 실습 1 — 다운로드와 구조 확인
1. 위 NSMC 저장소 설명에서 데이터 출처와 열 정의를 읽는다.
2. `ratings_train.txt`를 직접 저장하거나 Colab을 연다.
3. 아래 코드를 **Notion /code Python 블록**으로 따라 입력한다.
```python
import pandas as pd
from pathlib import Path
url = "https://raw.githubusercontent.com/e9t/nsmc/master/ratings_train.txt"
df = pd.read_csv(url, sep="\t", dtype={"id":"string"})
print("원본 행 수:", len(df))
display(df.head())
print(df.isna().sum())
print(df["label"].value_counts(dropna=False))
```
**확인:** 행 수, 열, 결측 값 수, label별 빈도와 실제 문장 5개 기록.

## 실습 2 — 정제와 무작위 추출
```python
clean = df.dropna(subset=["document","label"]).drop_duplicates(subset=["id"]).copy()
clean["document"] = clean["document"].astype(str).str.strip()
clean = clean[clean["document"].str.len() > 0]
clean["sentiment"] = clean["label"].map({0:"부정", 1:"긍정"})
sample = pd.concat([
    clean[clean["label"]==0].sample(n=50, random_state=42),
    clean[clean["label"]==1].sample(n=50, random_state=42)
]).sample(frac=1, random_state=42).reset_index(drop=True)
sample = sample.rename(columns={"id":"review_id","document":"review_text","label":"original_label"})
sample["source"] = "NSMC_movie"
sample.to_csv("week06_nsmc_collected_100.csv", index=False, encoding="utf-8-sig")
display(sample.head());print("샘플:",len(sample))
```
**확인:** 긍정 50개와 부정 50개인지, 동일 `review_id`가 없는지 확인.

## 실습 3 — 수집 메타데이터 기록
```python
# 수집 이력 저장: 출처와 방법은 데이터셋에 반드시 기록합니다.
from datetime import datetime, timezone
import json
record={"dataset":"NSMC 영화 리뷰","source_url":url,"collected_at_utc":datetime.now(timezone.utc).isoformat(),
        "original_count":len(df),"sample_count":len(sample),"method":"CSV/TSV 공개 파일 직접 다운로드",
        "note":"영화 리뷰(긍/부정)이며 쇼핑 리뷰(긍/부정/중립)와 도메인/레이블 차이 있음"}
Path("week06_collection_record.json").write_text(json.dumps(record,ensure_ascii=False,indent=2),encoding="utf-8")
print(record)
```
**결과물:** `week06_nsmc_collected_100.csv`, `week06_collection_record.json`.

## 실습 4 — 기존 워크북과 연결
1. 기존 쇼핑몰 합성 데이터(긍정/부정/중립)와 NSMC 영화 리뷰(긍정/부정)를 비교한다.
2. 직접 리뷰 10건을 읽어 수작업 감성 라벨을 기록한다.
3. NSMC 리뷰에 쇼핑몰 리뷰용 키워드 사전을 적용하면 오류가 나는 이유를 토의한다.
4. 출처·도메인·라벨 기준이 달라 두 데이터셋 결과를 직접적인 성능 비교로 해석하면 안 되는 이유를 작성한다.
