## 2. 수업용 표본 `week06_reviews_300.csv`
`tools/build_week06_data.py`와 **워크북 0 노트북이 같은 규칙**으로 만든다 (MD5 `826290503dfc1ab898089886d3225ba0`).

1. 문장 앞뒤 공백 제거, 연속 공백 1칸으로
2. 완전히 같은 문장이 2번 이상 나오면 **모두 제외** (184행)
3. 개인정보·외부 링크로 보이는 문장 제외: 전화번호 형태 숫자, `@`, `http`, `www.`, `.com` (122행)
   ※ 이름·주소처럼 규칙으로 못 잡는 개인정보가 있을 수 있으므로 읽다가 발견하면 강의자에게 알린다.
4. 길이 10~150자만 사용 (4,271행 제외) → 후보 195,423행 (별점 1: 35,927 · 2: 61,408 · 4: 18,752 · 5: 79,336)
5. 별점(1·2·4·5)별 75건씩 무작위 추출(`random_state=2026`) 후 섞기 → **300건**

| 열 | 설명 |
|---|---|
| `review_id` | R001 ~ R300 (수업용 번호) |
| `src_line` | 원자료 몇 번째 줄인지 (출처 추적용) |
| `rating` | 별점 1·2·4·5 |
| `rating_label` | 별점으로 붙인 **참고 라벨**: 4~5점 = 긍정, 1~2점 = 부정 |
| `review_text` | 후기 문장 (맞춤법·줄임말·이모티콘 원문 그대로) |

## 3. 꼭 알아야 할 한계
- **별점 라벨은 사람이 문장을 읽고 붙인 정답이 아니다.** 별점 2점인데 "배송도 빠르고 적극 추천합니다"(R009)처럼 본문과 별점이 어긋나는 후기가 있다. 이 라벨로 계산한 정확도는 "별점과 얼마나 맞는가"일 뿐이다.
- 별점 3점이 없으므로 **중립 리뷰가 없다.** 실제 쇼핑몰 리뷰에는 3점·애매한 리뷰가 많아 실제 성능은 더 낮을 수 있다.
- 표본은 별점별 75건으로 맞춘 것이라 **실제 쇼핑몰의 별점 비율(5점이 대부분)과 다르다.**
- 2020년 여름 네이버 쇼핑 후기다. 상품군·말투·시기가 달라지면 결과가 달라진다.
- 후기에는 상표명·은어·비속어·오타가 섞여 있다. 수업 자료로 분석만 하고, 원문을 다른 곳에 대량으로 다시 올리지 않는다.
